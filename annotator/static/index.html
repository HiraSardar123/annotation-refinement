How to use

  1. Left is the human annotation, exactly as in the rgb_masks of train / test. It is only a reference.
  2. Right ("My edit") is what gets saved. It starts from the SAM-refined masks (final\spatter_refined), or from your last save.
  3. Inspect (V): click an object in either image. Its card appears on the right: change its class, replace it with the human or SAM version, or delete it. Its match on the other side is highlighted.
  4. Fix with the tools on the left. They always work on My edit. The grey box under the tools says what the active tool does.
  5. Save & next ▶ (Ctrl+Enter) marks the image reviewed and opens the next one -- use it on every image, also when you changed nothing. Only saved images count as reviewed; moving on with ▶ or the arrow keys does not save. ⏭ Next unreviewed jumps to any image you skipped. Images go to edited_in_progress. As soon as every image of an experiment folder is reviewed, that folder is moved to edited. Tick Only what's left to see just the unreviewed images of folders you have started. Nothing is written into train, test or final. ✓ marks reviewed images and complete folders.

Mouse wheel zooms, right-drag or Space pans, F fits. 1 / 2 / 3 / 4 switch the view (Photo / Outline / Overlay / Mask). [ and ] change the brush size. Ctrl+Z / Ctrl+Y undo and redo. ← → change image. Esc clears the selection.
